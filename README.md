# corp-mega

Bundle publicado da aplicação de telemóvel da CO.RP Gestão (PWA).

Gerado por `python3 mobile/build.py` no repositório `corp-gestao`. **Não
editar aqui**: as alterações fazem-se lá e voltam a construir-se.

São ficheiros estáticos: HTML, CSS, JS, ícones e fontes. Não há aqui nenhum
dado do atelier — projetos, clientes, horas e faturação vivem no SharePoint,
atrás da autenticação Microsoft de cada pessoa. O `config.js` é a
configuração desta instalação (tenant, clientId, caminho do ficheiro
editorial) e é servido publicamente, como qualquer ficheiro de um site
estático.
